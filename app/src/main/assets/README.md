# RiskWatch Android App Assets

This directory contains asset files required for the RiskWatch Android App, including necessary credentials that should **not** be committed to version control.

## Required Credential Files

You must create the following files in this directory (`app/src/main/assets/`) based on the provided templates or instructions:

1.  **`api_key.txt`**
    *   **Purpose:** Contains the API Key for Login with Amazon (LWA).
    *   **Setup:**
        1.  Obtain the API Key from the **Android/Kindle Settings** tab of your LWA Security Profile on the [Amazon Developer Console](https://developer.amazon.com/home.html). Make sure your app's package name (`com.ece441.riskwatch`) and signing certificate fingerprint(s) are correctly registered there.
        2.  Create a file named `api_key.txt` in this directory.
        3.  Paste the generated API Key as the **only content** in this file.
    *   *This file is ignored by Git (`.gitignore`).*

2.  **`alexa_skill.json`**
    *   **Purpose:** Contains the Client ID and Client Secret for the associated RiskWatch Alexa Skill, used for sending Proactive Events.
    *   **Setup:**
        1.  Obtain your Alexa Skill's credentials, for example, by using the ASK CLI command: `ask smapi get-skill-credentials --skill-id <your-riskwatch-skill-id>`
        2.  Create a file named `alexa_skill.json` in this directory.
        3.  Paste the credentials into the file using the following JSON format:
            ```json
            {
              "clientId": "amzn1.application-oa2-client.YOUR_SKILL_CLIENT_ID",
              "clientSecret": "YOUR_SKILL_CLIENT_SECRET"
            }
            ```
        4.  Replace the placeholder values with your actual Skill Client ID and Secret.
    *   *This file is ignored by Git (`.gitignore`).*

## Development Setup Summary

1.  Clone the repository.
2.  Ensure you have the necessary Android SDK components installed.
3.  Create and populate `api_key.txt` as described above.
4.  Create and populate `alexa_skill.json` as described above.
5.  Ensure `local.properties` exists (usually generated by Android Studio) containing the path to your Android SDK (e.g., `sdk.dir=/path/to/your/android/sdk`).
6.  Build and run the project in Android Studio.

For more detailed information about Login with Amazon setup, visit the [LWA documentation](https://developer.amazon.com/docs/login-with-amazon/documentation-overview.html).
For more information about Alexa Proactive Events, visit the [Proactive Events API documentation](https://developer.amazon.com/en-US/docs/alexa/smapi/proactive-events-api.html).
